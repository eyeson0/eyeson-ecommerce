# Changelog

All notable changes to EYESON will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-XX

### Added
- Initial project setup
- Frontend with React + TypeScript + Vite
- Backend with Express + Prisma
- Admin dashboard
- Database schema with Prisma
- Welcome page with eye-opening animation
- Homepage with hero section and collections
- Product browsing and search
- Shopping cart functionality
- Wishlist feature
- User authentication (login/signup/verification)
- Order management system
- Real-time order tracking
- Multiple payment methods (eSewa, Khalti, Fonepay)
- Multi-channel notifications (Email, SMS, WhatsApp)
- Light/Dark theme toggle
- Responsive mobile design
- Admin dashboard with analytics
- Courier management system
- Real-time GPS tracking

### Security
- JWT authentication
- Argon2id password hashing
- Rate limiting
- CORS protection
- Input validation
- CSRF protection

### Performance
- Image optimization
- Lazy loading
- Code splitting
- Minification
- Asset caching
