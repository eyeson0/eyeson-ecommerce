# EYESON Admin Dashboard

Admin panel for managing EYESON e-commerce platform.

## 🚀 Features

- 📊 Dashboard with analytics
- 📦 Order management
- 🛍️ Product management
- 👥 Customer management
- 🚚 Courier management
- 💳 Payment tracking
- 📊 Sales analytics

## 🛠️ Tech Stack

- React 18
- TypeScript
- Vite
- React Router
- TailwindCSS
- Recharts for analytics
